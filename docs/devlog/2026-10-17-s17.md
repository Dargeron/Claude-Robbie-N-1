# Block 15 — 2026-10-17, 15:03 UTC: the web build checked end to end, and a faster sim

## A browser check that would have caught a broken build

Until now nothing ran the game the way Albert would: the tests run the simulation headless, and the smoke test runs
the project. `tools/webcheck.sh` takes the packed web page, serves it locally, opens it in headless Chromium, and
waits for the station to start. With the user argument `perf` the station also runs a small benchmark and prints the
timings to the browser console. The check fails on any script error.

It earned its keep at once. My first version of the benchmark used a helper from `tools/`, which exported builds leave
out, so the exported game failed to parse. The project run was fine, so the smoke test passed; only the browser showed
it. Nothing broken was published, and a new lint test now fails if game code ever uses a class from `tools/` or
`tests/`. A second export-only problem showed up after that: a type the editor could infer but the export couldn't.
The webcheck caught that one too.

It also answers half of the oldest open question: the packed page loads and runs in a real browser (Chromium,
software rendering). What's left is whether claude.ai's frame allows it, which only Albert can see.

## A faster sim

The benchmark showed The Jellyfish's careful program taking 1.6 s to simulate one dive natively, far more than any
other room. The reason: every time Robbie asked "is a hostile near?", the sim traced a line of sight to all 24
jellyfish, including ones across the room that couldn't possibly be sensed. Two changes, both pure speed-ups:

- **Cheap tests first.** A body is only line-of-sight-checked if it's close enough to glow at Robbie or inside the
  lamp's reach.
- **Asked once per think.** The nearest sensed hostile is computed once per think and reused by every rule (and the
  Why? panel's readings) that asks again.

Every golden replay is unchanged, so every dive is exactly the same as before, only faster.

| Room (intended program, one dive) | Before (native) | After (native) | After (browser) |
| --- | --- | --- | --- |
| The Dark | 195 ms | 180 ms | 709 ms |
| The Jellyfish | 1559 ms | 338–353 ms | 402 ms |
| The Nursery | 549 ms | 326–351 ms | 479 ms |
| The Valve | 122 ms | 81–85 ms | 113 ms |
| The Listeners | 260 ms | 146–150 ms | 200 ms |
| The Nursery's survey of 20 | 8.3 s | 6.5–7.0 s | 9.0 s |

(The Dark's browser time includes the first dive's warm-up.) A survey in the slowest room takes about nine seconds in a
browser, with the progress strip filling in, and a single launch is under a second everywhere.
