Robbie at normal speed is a lot of quiet water. The speed button now starts on **AUTO**:

current speed is 2× or less, so every event still has its sound.

## The hunt's blind spot

While checking why the hunts never reported `lamp off` / `move 90` or `shoot` / `move_towards open_water` directly
(only their conditional cousins), I found the reason: the hunt skipped every two-rule program whose first rule had no
condition, because "an unconditional first rule hides the second". That's true for `move`, but not for `lamp` (a
setting, the reading continues) or `shoot`, `keep_distance` and `move_towards light` (they only apply sometimes).
Those pairs are now in the sweep, appended at the end so saved progress stays valid. A finished hunt resumes to try
them. The Valve hunt is doing that now.
